# FIELDWORK

FIELDWORK is a landing page for a fictional platform that helps students and beginner developers get more practical experience.

The idea behind the website is simple — instead of only watching tutorials or learning theory, users can practice by working on realistic projects, getting feedback, and gradually taking on more difficult challenges.

## What I Built

I created this website as a Front-End Development Intern assignment.

The page includes:

 Responsive navigation with a mobile menu
 Hero section with a sample challenge
 Trusted By section
 Features section
 Product / About section
 How It Works section
 Statistics
 Solutions / Use Cases
 Testimonials
 Pricing plans
 Challenges
 FAQ accordion
 Final CTA
 Footer
 Start Fieldwork form

The Start Fieldwork buttons open a form where the user can enter their name, email and preferred domain.

## About The Idea

I wanted to make something related to a problem that many students and beginners face — knowing the basics but not getting enough practice building things on their own.

So I designed FIELDWORK around the idea of learning through actual practice rather than just consuming more tutorials.
